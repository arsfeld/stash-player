Stash Player

Update feeds for Stash Player.

Linux (Flatpak)

Install from this repository and updates arrive through GNOME Software or flatpak update:

flatpak install --user https://arsfeld.github.io/stash-player/flatpak/dev.arsfeld.stash-player.flatpakref

Or open dev.arsfeld.stash-player.flatpakref. The repository alone: stash-player.flatpakrepo.

macOS

The Sparkle feed is appcast.xml.
